# instytut.14-200.pl

Static website of **Iławski Instytut Idei**, migrated from Google Sites.
Built with [Eleventy](https://www.11ty.dev/), plain HTML + one small CSS file, no frameworks or webfonts.

```sh
npm install
npm start        # dev server on http://localhost:8080
npm run build    # output in _site/, then regenerates vercel.json
```

## Hosting

- **Vercel**, static only (no functions). Project settings come from `vercel.json`; keep the dashboard fields empty.
- Domain `instytut.14-200.pl`. DNS is in Cloudflare (zone `14-200.pl`): `CNAME instytut → cname.vercel-dns.com`, **DNS only** (grey cloud), so Vercel issues the certificate.
- `vercel.json` is generated by `scripts/vercel-config.mjs` from `_site/_redirects` after every build. Vercel reads it from the repository, so **commit it** when the build says "updated".
- The same `_site/` also works on Netlify / Cloudflare Pages (they read `_redirects`).

## Editing in the browser

`https://instytut.14-200.pl/admin/` runs [Decap CMS](https://decapcms.org) (config: `src/static/admin/config.yml`).
Sign-in goes through [DecapBridge](https://decapbridge.com), so editors need no GitHub account.
DecapBridge commits to `yasiupl/instytut.14-200.pl` on GitHub with the site's access token, and Vercel deploys every commit in about a minute.

- Editors are invited by e-mail from the DecapBridge dashboard and sign in with a password or Google/Microsoft.
- The site in DecapBridge holds a fine-grained GitHub token (repository: this one; permission: Contents read/write). Renew it there before it expires.
- The `backend` block of the config comes from the DecapBridge dashboard.
- Uploaded images are converted to WebP (quality 80) but not resized: shrink large photos to about 1600 px before uploading.
- Pages (`src/pages/`) can be edited but not created or deleted in the CMS: their addresses are linked from everywhere.

## Regulamin (statut)

`dokumenty/regulamin.tex` is a verbatim transcription of the registered document (spelling and numbering unchanged, including the missing point 24).
`npm run regulamin` builds `src/static/dokumenty/regulamin.pdf` with Tectonic from nixpkgs. Commit the PDF, because Vercel does not build it.
The web version `src/pages/regulamin.md` has the same text: change both together.

## Layout

| Path | What |
| --- | --- |
| `src/aktualnosci/*.md` | News posts → `/aktualnosci/<slug>/`, listed on home, `/aktualnosci/` and in the feeds |
| `src/projekty/*.md` | Projects → `/projekty/<slug>/`, listed on `/projekty/` |
| `src/pages/*.md` | Standing pages (Laboratorium, Pracownia, O nas, Kontakt…) |

Front matter: `title`, `date`, `summary` (one line for lists), `image` (thumbnail), `image_alt`, `hero: true` (show `image` above the text, with `image_caption`), `area: "lab" \| "pracownia"`, `redirect_from`.
| `src/_data/site.js` | Site config: nav, contact, rel=me links, webmention + fediverse settings |
| `src/_includes/` | `base.njk` (shell), `page.njk` (article / h-entry), `home.njk` (h-feed) |
| `src/assets/` | `style.css`, `site.js`, images (WebP, ≤1600 px) |

Shortcodes inside Markdown: `{% youtube "ID", "title", "caption (HTML, optional)" %}`, `{% form "url", "title" %}`.

## Link previews (og:image)

The build makes one 1200×630 JPEG for each page in `_site/og/` (`scripts/og-image.mjs`, `sharp`). Do not link to `/og/` from content.

- Photo: the page's `image`. If the page has no `image`, the first local image in its content. If there is no image, a plain dark background.
- Text: the page title over the photo, with the site name above it. Pages without their own title (the home page) get the photo only.
- A page without a title and without a photo uses `site.ogImage` (`src/assets/og-default.png`, source `scripts/og-default.svg`).
- The fonts are in `scripts/fonts/` (Inter, SIL Open Font License), so the result does not depend on the build machine.
- The file name contains a hash of the photo and the title. A new title gives a new address, so apps show the new image. To make all images again after you change their look, increase `OG_VERSION` in `eleventy.config.js`.
- To test a preview, use the Facebook Sharing Debugger or opengraph.xyz.

## Old URLs

Every Google Sites path is kept. A page's `redirect_from` produces:

- `_site/_redirects`: 301s for Netlify / Cloudflare Pages (both raw and percent-encoded Polish characters);
- an HTML `meta refresh` stub at the old path, for hosts that don't read `_redirects`.

## IndieWeb & ActivityPub

- microformats2: `h-card` (footer), `h-entry` (news pages), `h-feed` (home page).
- Webmentions via [webmention.io](https://webmention.io). The account exists only after the first sign-in: sign in at webmention.io with `https://instytut.14-200.pl` and select the e-mail address (`rel="me" mailto:`). The code goes to that mailbox. Until then the endpoint answers `account … not found`. Mentions are shown under each news post.
- Feeds: `/feed.xml` (Atom), `/feed.json` (JSON Feed).
- Fediverse: the account `@instytut@14-200.pl` on the 14-200.pl hub (GoToSocial), no Bridgy Fed.
  Plan: `14-200.pl/docs/plan-instytut.md`. Until the account exists, `site.fediverse.active` is `false`
  and `/fediverse/` says "w przygotowaniu". Set it to `true` when the account works.
